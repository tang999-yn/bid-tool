标书拆解+技术标生成器 — 使用说明
====================================

一、准备工作：获取 API Key（必须）

推荐使用 DeepSeek，中文标书理解最好，价格最低。
一次完整拆解成本约 ¥0.06，充 10 块能用几百次。

注册地址：https://platform.deepseek.com
1. 手机号注册 → 点击左上角「API Keys」→「创建 API Key」→ 复制保存

备选方案：
- 豆包（火山引擎）：https://console.volcengine.com
- 通义千问（阿里云）：https://dashscope.aliyun.com
- Kimi（月之暗面）：https://platform.moonshot.cn


二、打开工具

网址：https://tang999-yn.github.io/bid-tool/
浏览器（Chrome/Edge 均可）打开即用，无需下载安装。


三、激活

打开页面 → 输入激活码 → 点击「激活」


四、设置 API Key

点击右上角「⚙️ 设置」→ 依次填写：
- API Key：粘贴第一步获取的 Key
- 服务商：选择对应的（默认 DeepSeek，无需改动）
- 端点：默认已填好，无需修改
- 模型：默认 deepseek-chat，无需修改
- 温度：默认 0.3，建议保持不变
- 填写完成自动保存


五、使用流程（四步走）

第①步  招标解析
- 上传招标文件（支持 PDF / DOCX / TXT）
- 点击「AI 智能解析招标文件」
- 等待 AI 逐条提取：基本信息、报价要求、资质条件、评分标准、废标条款、材料清单等 15 大类信息
- 耗时约 1-2 分钟

第②步  材料清单
- 切换到「材料清单」标签
- 点击「生成材料清单」
- AI 逐人逐证列出所有需准备的材料，标注关键/重要/一般级别
- 可对照清单逐项准备

第③步  技术标大纲
- 切换到「技术标大纲」标签
- 点击「生成技术标大纲」
- AI 对照招标评分标准，逐章标注得分点、配图建议
- 评分占比高的章节自动标⭐

第④步  技术标生成（核心功能）
- 切换到「标书生成」标签
- 勾选需要生成的章节 → 点击「逐节生成技术标」
- AI 逐节编写详细技术内容，每节 2000-3500 字
- 不同章节匹配不同专家角色（施工/安全/质量/进度各有侧重）
- 生成后可单独修改或重新生成某一节


六、导出

点击右上角「📥 导出 Word」→ 生成 .docx 文件 → WPS 或 Word 直接打开编辑。
所有内容也可在各 Tab 内点击「复制」按钮单独复制。


七、注意事项

1. 所有数据存储在本地浏览器，不上传任何服务器
2. 上传的招标文件不离开你的电脑
3. API Key 仅存储在浏览器本地
4. AI 生成的标书内容需要结合实际情况审核修改
5. 数据占位符「____」处请填入实际数据


八、常见问题

Q：为什么上传文件后没反应？
A：请检查文件格式（PDF/DOCX/TXT），文件不要超过 50MB。

Q：提示「API Key 无效」？
A：检查 Key 是否完整复制，注意不要包含多余空格。

Q：生成的内容不完整？
A：复杂文档建议适当裁剪后再上传，保留核心章节。

Q：如何续费？
A：闲鱼搜索「标书拆解+技术标生成器」联系卖家。

九、备用方案

如果网页打不开，下载百度网盘里的备份文件，用浏览器打开 index.html 即可。
功能和在线版完全一致，激活码通用。
